### 4.4.6.5 Spesifikasi Basis Data

Spesifikasi basis data merupakan penjelasan mengenai rincian struktur tabel yang ada pada sistem. Berikut adalah spesifikasi basis data Sistem Informasi Pengembangan Kompetensi Pegawai (SIPJP):

#### 1. Spesifikasi Basis Data Super_Admin

Nama File       : Super_Admin
Media           : Hardisk
Isi             : Data Akun Pengelola Utama BKPSDMD
Organisasi      : Index Sequential
Primary Key     : id_admin
Panjang Record  : 70 byte
Jumlah Record   : 1 Record
Struktur        :

Tabel 4. 6 Spesifikasi Basis Data Super_Admin

| No | Nama Field | Jenis | Lebar | Desimal | Keterangan |
| :---: | :--- | :---: | :---: | :---: | :--- |
| 1 | id_admin | Varchar | 20 | - | ID Pengenal Super Admin (PK) |
| 2 | password | Varchar | 50 | - | Kata Sandi Akun Admin |
